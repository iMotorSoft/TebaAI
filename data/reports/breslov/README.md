# Breslov Reports

Generated Breslov evidence and validation outputs live here.

Use date-scoped directories:

- `YYYY-MM-DD-topic/` for a closed validation or operational evidence set.
- `YYYY-MM-DD-topic/backups/` for generated JSON snapshots and manifests.
- `YYYY-MM-DD-topic/probe/` for generated parser or extraction probe outputs.

Architecture decisions stay in `docs/adr/`. Stable policies stay in `docs/` or `lat.md/`.

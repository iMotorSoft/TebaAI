# V2 → V3 scope

## V2 reused unchanged

Candidate discovery, stable region IDs, forward canonical serializer and Markdown ranges, note-marker recognizer, overlap predicates, native paint trace, quality equivalence and all six V2 note proofs. V1/V2 files are not edited. The worker has no V3 caller.

## V2 strengthened / restricted in V3

New body support requires actual native ruled-panel geometry, independently anchored lower note separator, centered upper caption, wide single-panel ownership, homogeneous text size (except explicit superscripts), source/geometry order and visible horizontal native direction. Text labels alone remain insufficient. Existing V2 note verdicts are not relaxed. All five V1 false zones remain permanent development regressions.

## V3 new

`RegionCertificateV3`, four explicit body proofs, deterministic editorial IDs and adjacent-page continuation links. Every page keeps its own immutable source identities, geometry and Markdown slices. Body provenance and body quality are separate: native horizontal paint proves direction, not exact character equivalence. ACCEPTED still requires unchanged native-token and Markdown-decoration equivalence. No text repair or ligature/search normalization added.

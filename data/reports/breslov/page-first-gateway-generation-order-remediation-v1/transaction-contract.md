# Transaction boundary

`persist_document_and_pages` uses `transaction(pool)` and `conn.transaction()`. The document, run, logical identity, document/logical link, BUILDING generation, text/pages, manifest and job ownership update use the same connection and transaction. An exception propagates, rolling back the entire registration, including newly created parents; an existing logical identity is preserved. No pointer is written.

Synthetic tests use the real context manager on a real connection, nested in an unconditional rollback fixture. Registration errors roll back to its savepoint; independent reads verify zero document/logical/run/generation/pointer artifacts. A controlled exception after all parents and a real generation INSERT NotNullViolation are injected. The latter intentionally changes only a negative-control parameter to NULL; it is not a FK/binding defect or production binding change. Both then retry the identical failed attempt successfully. The outer rollback removes all controlled fixture rows, including successful attempts. This validates transaction semantics without persisting synthetic data.

The gateway existing retry policy rejects a document UUID collision before resource ownership. It does NOT resume a committed attempt. Tests verify rejection is side-effect-free, not introduce new idempotency semantics. A distinct pipeline version reuses the logical identity and creates a distinct BUILDING generation/run without pointer theft. Completion through the unchanged gateway finalize produces CANDIDATE and completed run, still invisible. Its source-copy function is isolated to the fixture temporary directory; no source durability claim. No extraction, embeddings or Milvus calls.

The schema imposes a partial order: document logical_id starts nullable, so physical document and run may be inserted before logical identity resolution. What must precede generation are both the valid run and the linked document/logical pair. This is the minimal corrected order; there is no deferred constraint, schema or generation-policy change.

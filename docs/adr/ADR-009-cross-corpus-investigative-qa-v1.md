# ADR-009: Cross-corpus investigative QA V1

Estado: accepted and implemented.

El batch cruza exclusivamente el corpus local: chunks de Kitzur, páginas finalizadas de LM II y la vista investigativa de LH. No usa vector, IA ni fuentes externas. La salida clasifica evidencia literal, nominal, de nota o paralelo temático; nunca promueve una coocurrencia a relación doctrinal.
